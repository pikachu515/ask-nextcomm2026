# 원본 자료

## 저장소에 있는 것

주최 측이 배포한 원본이다. 내용은 [docs/contest/rules.md](../docs/contest/rules.md)에 옮겨 놓았다.

|---|---|
| `official/01_참가신청서_양식.hwp` | 참가신청서 양식. 각자 복사해 저장소 밖에서 작성한다 |

## 저장소에 올리지 않는 것

각자 보관한다. 꼭 저장소 폴더 안에 두고 싶으면 `refs/private/`에 넣는다. 그 폴더는 git이 무시한다.

| 자료 | 올리지 않는 이유 | 저장소 안의 대체 문서 |
|---|---|---|
| 연구실 브리핑 「교차로 4D 레이다·라이다·RSU 활용안」 | 팀 밖 작성자의 문서다 ([결정 0003](../docs/decisions/0003-lab-briefing-scope.md)) | [docs/design/roadside-sensing.md](../docs/design/roadside-sensing.md) |
| 팀원의 「제안서 구성안」 PDF | 내용이 쪽 파일로 옮겨졌다 | [docs/proposal](../docs/proposal/README.md) |
| 팀원의 「ASK + SafeLink 실행보고서」 PDF | 내용이 설계 문서와 코드로 옮겨졌다 | [docs/design/safelink.md](../docs/design/safelink.md), [sim/safelink](../sim/safelink/README.md) |
| 작성한 참가신청서 | 개인정보가 들어 있다 | [docs/application/application-form.md](../docs/application/application-form.md) |
