# 모의실험

ASK의 각 기능이 효과를 내는 조건을 확인한 가정값 기준 모의실험이다. 실제 도로나 5G 망에서 측정한 값이 아니며, 제안의 방향을 검토하는 보조 근거로 사용한다.

| 폴더 | 확인하려는 것 | 방법 |
|---|---|---|
| [surge](surge/README.md) | 요청이 몰릴 때 차로 점유를 얼마나 줄이는가 | 차량 200대 도시, 2초 단위 시간 진행 |
| [safelink](safelink/README.md) | 긴급 정보가 제때 유효하게 도착하는 비율 | 두 경로 메시지 전송, 혼잡·장애 구간 |
| [blackout](blackout/README.md) | 정전 시 교차로의 사전 알림 효과 | surge와 같은 조건에 사전 알림 추가 |
| [selection](selection/README.md) | 자원 부족 시 정보 선택의 누락 감소 효과 | 교차로 좌표 기반 가림 계산 |
| [deadline](deadline/README.md) | 통신·AI 처리 순서를 마감시각으로 통합한 효과 | 두 단계 대기열 사건 기반 계산 |
| [sumo_crossing](sumo_crossing/README.md) | 늦은 응답이 뒤차를 포함한 교통에 주는 영향 | SUMO 1.28 + TraCI 차량 제어 |

## 실행

```bash
pip install -r ../requirements.txt
```

```bash
python surge/surge_sim.py
python safelink/safelink_eval.py
python blackout/blackout_sim.py
python selection/selection_sim.py
python deadline/deadline_sim.py
python sumo_crossing/crossing_sumo.py
```

결과는 각 폴더의 `results`에 저장된다. 시드가 고정되어 있어 다시 실행하면 같은 값이 나온다.

## 실험 원칙

- **같은 시드에서는 모든 방식이 같은 난수를 사용한다.** 방식 간 차이가 정책에서만 생기게 한다.
- **평균과 95% 신뢰구간을 함께 보고한다.** 신뢰구간은 난수의 흔들림에 대한 것이며 실제 도로에서의 확실성이 아니다.
- **불리한 결과도 함께 적는다.** 각 README의 "읽는 법"에 제안 방식이 이점이 없거나 불리한 조건을 정리했다.
- **가정값은 표로 밝힌다.** 코드의 상수와 각 README의 가정값 표가 일치한다.

## 이 실험이 다루지 않는 것

- 5G 무선 구간의 자원 할당, 전파 환경, 재전송은 단순화했다. 지연과 손실은 정해 넣은 값이다.
- 요청 빈도, 관제 처리 시간 등 운영 수치는 공개 자료가 없어 가정했다.
- 메시지의 도착이 곧 안전한 주행을 뜻하지는 않는다. 사고 감소율 같은 수치는 제시하지 않는다.
