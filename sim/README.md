# 모의실험

제안의 방향이 맞는지 컴퓨터로 해 본 가상 실험이다. 대회는 시제품을 요구하지 않으므로 이 결과는 보조 근거다. 수치는 모두 가정값에서 나왔고, 실제 통신망이나 실제 도로에서 잰 값이 아니다.

| 모의실험 | 답하려는 질문 | 쓰는 쪽 | 사실 카드 |
|---|---|:-:|:-:|
| [surge](surge/README.md) | 요청이 한꺼번에 몰릴 때 도로를 막는 차량을 얼마나 줄일 수 있는가 | 1, 10 | S-01 |
| [safelink](safelink/README.md) | 긴급한 정보가 제때, 쓸 수 있는 상태로 도착하는 비율을 얼마나 높일 수 있는가 | 6 | S-02 |

## 실행

Python 3.10 이상이 필요하다.

```bash
pip install -r requirements.txt
```

```bash
python sim/surge/surge_sim.py
```

```bash
python sim/safelink/safelink_eval.py
```

두 실험 모두 결과를 각자의 `results` 폴더에 쓴다. 시드가 고정돼 있어 다시 돌려도 같은 값이 나온다.

## 결과 한눈에

**요청 폭주** (차량 200대, 관제사 5명, 요청이 10배로 느는 30분, 시드 100개)

| 방식 | 차로 점유 차량·분 | 사람만 대비 |
|---|--:|--:|
| 사람만 | 2,853 | 기준 |
| 교차로 응답 추가 | 1,777 | 38% 감소 |
| 통신 보장 추가 | 919 | 68% 감소 |
| 우선 배정과 대피 추가 | 216 | 92% 감소 |

**긴급 정보 전달률** (30초, 보조 경로 준비 80ms, 시드 100개)

| 방식 | 제때 유효하게 도착한 비율 | 추가 전송 |
|---|--:|--:|
| 온 순서대로 | 53.9% | 0% |
| 급한 순서대로 | 92.1% | 0% |
| 필요할 때만 두 경로 | 96.2% | 7% |
| 항상 두 경로 | 98.1% | 27% |

## 실험할 때 지키는 것

- **같은 시드에서는 모든 방식이 같은 운을 만난다.** 방식 사이의 차이가 선택에서만 생기게 한다.
- **시드 100개로 반복한다.** 평균과 95% 신뢰구간을 함께 낸다. 이 구간은 난수의 흔들림에 대한 것이지, 실제 도로에서의 확실성이 아니다.
- **불리한 결과를 숨기지 않는다.** 제안한 방식이 지는 조건도 적는다.
- **가정값은 표로 밝힌다.** 코드의 상수와 각 README의 표가 같아야 한다.
- **코드를 고치면 다시 돌린다.** 결과 파일과 [사실 카드](../docs/evidence/facts.md)의 S-01, S-02를 함께 고친다.

## 이 실험이 말하지 못하는 것

- 통신의 물리 계층, 전파 환경, 재전송은 들어 있지 않다. 지연과 손실은 정해 넣은 값이다.
- 차량의 실제 움직임은 들어 있지 않다. 메시지가 잘 도착하는 것과 차량이 안전하게 달리는 것은 다르다.
- 요청이 얼마나 자주 생기는지, 사람이 처리하는 데 얼마나 걸리는지는 공개된 운영 수치가 없어 가정했다.
- 그래서 "몇 % 줄인다"는 숫자보다 **어떤 조치가 효과가 큰지의 순서**를 읽는 것이 맞다.
