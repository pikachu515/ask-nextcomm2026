# 모의실험 개요

ASK의 각 기능이 효과를 내는 조건을 검증한 가정값 기반 모의실험입니다. 실제 도로나 5G 망에서 측정한 값이 아니며, 제안의 타당성을 검토하는 보조 근거로 사용합니다.

| 폴더 | 검증 목적 | 방법 |
|---|---|---|
| [surge](surge/README.md) | 요청 집중 시 차로 점유 감소 효과 | 차량 200대 도시, 2초 단위 시간 진행 |
| [safelink](safelink/README.md) | 긴급 정보의 제시간 유효 도착 비율 | 두 경로 메시지 전송, 혼잡·장애 구간 |
| [blackout](blackout/README.md) | 정전 시 교차로 사전 알림 효과 | surge와 동일 조건에 사전 알림 추가 |
| [selection](selection/README.md) | 자원 부족 시 정보 선택의 누락 감소 효과 | 교차로 좌표 기반 가림 계산 |
| [deadline](deadline/README.md) | 통신·AI 처리 순서의 마감시각 통합 효과 | 2단계 대기열 이산 사건 모델 |
| [sumo_crossing](sumo_crossing/README.md) | 응답 지연이 후속 차량을 포함한 교통에 미치는 영향 | SUMO 1.28 + TraCI 차량 제어 |

## 실행 방법

```bash
pip install -r ../requirements.txt
```

```bash
python surge/surge_sim.py
python safelink/safelink_eval.py
python blackout/blackout_sim.py
python selection/selection_sim.py
python deadline/deadline_sim.py
python sumo_crossing/crossing_sumo.py
```

결과는 각 폴더의 `results`에 저장됩니다. 난수 시드가 고정되어 있어 재실행 시 동일한 결과가 재현됩니다.

## 실험 원칙

- **동일 시드에서는 모든 방식이 같은 난수를 사용합니다.** 방식 간 차이가 정책에서만 발생하도록 통제합니다.
- **평균과 95% 신뢰구간을 함께 보고합니다.** 신뢰구간은 난수 변동에 대한 것이며, 실제 도로 환경에서의 확실성을 의미하지 않습니다.
- **불리한 결과도 함께 기술합니다.** 각 README의 "결과 해석"에 제안 방식의 이점이 없거나 불리한 조건을 정리했습니다.
- **가정값을 표로 공개합니다.** 코드의 상수와 각 README의 가정 조건 표는 일치합니다.

## 한계 및 적용 범위

- 5G 무선 구간의 자원 할당, 전파 환경, 재전송은 단순화했으며, 지연과 손실은 설정값입니다.
- 요청 빈도, 관제 처리 시간 등 운영 수치는 공개 자료가 없어 가정값을 사용했습니다.
- 메시지 도착이 곧 안전한 주행을 의미하지는 않으므로, 사고 감소율과 같은 수치는 제시하지 않습니다.

## 향후 계획

- **ns-3 5G-LENA:** 정보 선택 실험의 "방송 1건 = 개별 전송 4단위" 가정과 마감시각 실험의 무선 구간을 실제 5G 자원 모델로 재측정합니다.
- **SUMO 확장:** 신호 교차로와 다수 교차로로 확장합니다.
