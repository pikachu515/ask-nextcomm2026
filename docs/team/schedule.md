# 일정

접수 마감은 2026년 11월 18일(수)이다. 팀 목표는 당일 오전 제출이다. 역할은 [roles.md](roles.md)를 따른다.

## 예선까지

### 11월 16일 (월): 글을 확정한다

- [ ] 역할과 대표자를 정한다
- [ ] 팀명과 아이디어명을 정한다 ([참가신청서 안내](../application/application-form.md))
- [ ] 각자 맡은 쪽의 "슬라이드에 넣을 글"을 읽고 고친다
- [ ] [결정 0002](../decisions/0002-safelink-as-comm-module.md)의 남은 질문을 통신 담당과 정한다
- [ ] 연구실 설계를 참고했다는 표기 문구를 정한다 ([결정 0003](../decisions/0003-lab-briefing-scope.md))
- [ ] 사실 카드의 '팀 출처' 항목에 링크를 채운다 (F-10, F-15, F-18)

### 11월 17일 (화): 슬라이드를 만들고 서로 읽는다

- [ ] 슬라이드 10쪽을 조립한다. 총괄이 틀을 만들고 각자 맡은 쪽을 채운다
- [ ] 그림을 넣는다: 흐름 그림(4쪽), 전달률 막대그래프(6쪽), 비교표(8쪽), 모의실험 그래프와 로드맵(10쪽)
- [ ] 쪽마다 출처를 적는다
- [ ] 짝을 바꿔 읽고 쉬운 말 검사를 한다
- [ ] 사실 카드에서 '원문 확인'이 아닌 항목의 원문을 연다. 확인하지 못한 항목은 슬라이드에서 뺀다
- [ ] 전공이 다른 친구 한 명에게 보여 주고 1분 안에 무슨 서비스인지 되물어 본다
- [ ] 참가신청서를 작성하고 대표자가 서명한다
- [ ] PDF로 바꿔 쪽수와 글자 깨짐을 확인한다

### 11월 18일 (수) 오전: 낸다

- [ ] [제출 체크리스트](../contest/submission-checklist.md)를 세 명이 함께 넘긴다
- [ ] 파일명을 `팀명_아이디어명`으로 맞춘다
- [ ] 구글폼으로 제안서와 참가신청서를 낸다
- [ ] 제출 확인 화면을 캡처해 팀 대화방에 올린다

## 본선에 가면 보강할 것

지금은 시간이 없어 미룬 일이다.

- 모의실험을 교통 시뮬레이터(SUMO)와 이어 차량의 움직임까지 본다
- 통신 모듈의 남은 질문을 실험한다 ([safelink.md](../design/safelink.md)의 "다음에 할 일")
- 요청 폭주 모의실험의 가정값에 근거를 단다 ([sim/surge](../../sim/surge/README.md))
- 연구실 장비로 시연 세 장면을 찍는다
