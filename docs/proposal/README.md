# 아이디어 제안서

PPT 또는 PDF 10쪽 이내로 내는 예선 제출물이다. 쪽마다 파일 하나로 관리하고, 여기 적힌 글을 슬라이드에 옮긴다.

## 전체 흐름

무인차가 실제로 도로를 막은 사고에서 시작해(2~3쪽), 교차로가 먼저 답하는 네 단계를 보이고(4~5쪽), 통신이 맡는 일을 설명한 뒤(6~7쪽), 다른 방식과의 차이(8쪽), 누가 쓰는지(9쪽), 어떻게 확인하고 넓히는지(10쪽)로 끝난다.

## 쪽 파일을 읽는 법

| 절 | 내용 |
|---|---|
| 이 쪽이 전할 한 가지 | 이 쪽을 본 사람이 기억해야 할 한 문장 |
| 슬라이드에 넣을 글 | 슬라이드에 그대로 옮기는 글. 줄여도 되지만 늘리지 않는다 |
| 그림 | 넣을 그림과 그리는 법 |
| 말로 풀면 | 발표하거나 설명할 때 쓰는 말 |
| 근거 | [사실 카드](../evidence/facts.md)의 번호 |
| 남은 일 | 이 쪽에서 아직 정하지 못한 것 |

## 쓸 때 지키는 것

- **쉬운 말로 쓴다.** 독자는 통신을 배우지 않은 대학생이다. [쉬운 말 쓰기 규칙](../plain/style-guide.md)을 따른다.
- **한 쪽에 메시지 하나.** 쪽 제목만 이어 읽어도 이야기가 되어야 한다.
- **숫자는 사실 카드에 있는 것만 쓴다.** 모의실험 수치에는 "가정값 기준"을 붙인다.
- **단정하지 않는다.** "보장", "무중단", "세계 최초"를 쓰지 않는다.
- **시연 범위와 제안 범위를 구분한다.** 시연은 시험용 무선 장비와 도로변 엣지 PC, 제안은 5G 기지국과 통신사 엣지와 AI-RAN이다.
- **답이 없으면 멈춘다는 점을 함께 쓴다.** "멈추지 않는다"를 약속하지 않는다.

## 슬라이드로 옮길 때

- 글보다 그림을 먼저 놓는다. 표는 한 쪽에 하나만 둔다.
- 출처는 쪽 아래에 작은 글씨로 적는다. 사진을 쓰면 출처와 사용 가능 여부를 확인한다.
- 강조색은 한 가지만 쓴다. 저장소 대문의 남색과 민트색을 써도 된다.
- 파일 전체가 10쪽을 넘지 않는다. 표지를 따로 두지 않고 1쪽이 표지를 겸한다.
- 완성하면 PDF로 바꿔 다시 열어 보고, 파일명을 `팀명_아이디어명`으로 맞춘다.
