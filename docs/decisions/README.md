# 결정 기록

방향에 영향을 주는 결정을 짧게 남긴다. 나중에 합류한 사람이나 AI 도우미가 "왜 이렇게 됐는지"를 다시 묻지 않게 하려는 것이다.

| 번호 | 결정 | 상태 |
|---|---|---|
| [0001](0001-combined-plan.md) | 문제를 "가려진 교차로"에서 "막힌 무인차의 질문"으로 넓힌다 | 채택 |
| [0002](0002-safelink-as-comm-module.md) | SafeLink를 ASK의 통신 모듈로 넣는다 | 제안, 팀 확인 필요 |
| [0003](0003-lab-briefing-scope.md) | 연구실 브리핑은 2단계의 센서 구성과 시연 장면에만 참고한다 | 채택, 표기 방식은 팀 확인 필요 |

## 쓰는 법

- 파일명은 `번호-짧은-제목.md`다. 번호는 이어서 붙인다.
- 항목은 상태, 배경, 결정, 이유, 버린 대안, 남은 질문 순서로 쓴다.
- 결정을 바꿀 때는 기존 파일을 지우지 않는다. 새 파일을 만들고 옛 파일의 상태를 "0005로 대체" 식으로 고친다.
