# 0001. 문제를 "가려진 교차로"에서 "막힌 무인차의 질문"으로 넓힌다

| 항목 | 내용 |
|---|---|
| 상태 | 채택 (2026-11-12) |
| 관련 쪽 | 1~5쪽, 9쪽 |

## 배경

처음 구성안은 대형차 가림이나 카메라 오염으로 자율주행차가 신호와 횡단 구역을 못 볼 때, 교차로 정보를 요청해 받는 서비스였다. 검토하면서 네 가지가 걸렸다.

- 카메라 오염은 교차로를 지난 뒤에도 계속되므로 교차로 정보로는 풀리지 않는다.
- 응답 기한이 0.85~3.7초인데 작은 메시지는 일반 5G로도 수십 ms면 간다. 차세대통신이 꼭 필요한 이유가 약했다.
- 첫 고객으로 잡은 셔틀버스는 차체가 커서 가림의 피해가 상대적으로 작다.
- 문제 근거로 든 사고가 가림과 직접 관련이 없었다.

## 결정

문제를 "무인차가 스스로 판단하지 못할 때 기대는 통신과 사람이 한꺼번에 부족해지는 순간"으로 넓힌다. 가려진 교차로는 그 질문 가운데 하나로 남긴다. 답은 차량, 교차로, 사람 관제사, 안전 대피의 네 단계로 구한다.

## 이유

- **실제 사고가 있다.** 2023년 크루즈, 2025년 웨이모 사고는 통신 혼잡과 요청 폭주로 무인차가 도로를 막은 사례다(F-03, F-04).
- **국내 수요가 예정돼 있다.** 2026년 7월 가이드라인으로 무인차에 원격관제가 필수 요건이 됐고, 광주에 200대 이상이 들어온다(F-06, F-07).
- **통신이 빠지면 성립하지 않는다.** 요청이 몰릴 때 누구를 먼저 연결할지는 통신망만 정할 수 있다.
- **기존 작업을 살린다.** 서비스명 ASK, 요청과 응답 구조, 응답 마감시각, 플랜 A~D가 네 단계 구조에 그대로 들어간다.

## 버린 대안

| 대안 | 버린 이유 |
|---|---|
| 처음 구성안 그대로 | 위 네 가지 문제가 남는다 |
| 기존 CCTV로 대형차 우회전 경고 | 통신도 자율주행도 얕다는 팀 내 평가 |
| 통신 품질 예보 단독 | 예측 정확도를 미리 장담할 수 없다. 확장 항목으로 남긴다 |
| 기지국 전파로 보행자 감지 | 상용화가 2030년 이후로 예상되어 창업 아이디어로 약하다. 로드맵에 한 줄로 남긴다 |

## 남은 질문

- 팀 세 명이 모두 이 방향에 동의했는지 여기에 기록한다.
