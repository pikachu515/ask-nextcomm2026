# 제출 체크리스트

접수 마감은 2026년 11월 18일(수)이다. 팀 목표는 당일 오전 제출이다. 규정의 근거는 [rules.md](rules.md)에 있다.

## 아이디어 제안서

- [ ] 파일 전체가 10쪽 이내다 (표지를 넣었다면 표지 포함)
- [ ] PPT 또는 PDF다. PDF로 바꾼 뒤 글자와 그림이 깨지지 않았는지 다시 열어 봤다
- [ ] 파일명이 `팀명_아이디어명`이다
- [ ] 다섯 필수 항목이 모두 들어 있다: 문제 및 필요성, 아이디어 내용, 차세대통신 활용, 차별성 및 융합성, 사업화 및 확장 가능성
- [ ] 첫 쪽만 읽어도 문제, 해결, 통신의 역할이 보인다
- [ ] 모든 숫자가 [사실 카드](../evidence/facts.md)에 있고, 쪽마다 출처가 적혀 있다
- [ ] 사실 카드에서 '원문 확인'이 아닌 항목은 원문을 열어 확인했다
- [ ] 모의실험 수치 옆에 "가정값 기준"이 적혀 있다
- [ ] 그림과 사진의 출처를 적었다. 남의 사진을 썼다면 사용해도 되는지 확인했다
- [ ] "보장", "무중단", "세계 최초" 같은 단정 표현이 없다
- [ ] 통신을 배우지 않은 친구에게 보여 주고 1분 안에 무슨 서비스인지 되물어 봤다

## 참가신청서

- [ ] 참가 형태를 '팀 참가'로 표시했다
- [ ] 팀명과 아이디어명이 제안서 파일명과 같다
- [ ] 대표자 정보(이름, 소속대학, 학과, 학년, 휴대폰, 이메일)를 채웠다
- [ ] 팀원 정보 표에 세 명 모두 적고 '역할' 칸을 채웠다 ([역할 문구](../application/application-form.md))
- [ ] 세 명 모두 개인정보 수집·이용 동의 칸에 표시했다
- [ ] 날짜와 대표자 서명을 넣었다
- [ ] 세 명 모두 재학생이다 (휴학생과 대학원생은 참가할 수 없다)

## 제출

- [ ] 구글폼에 두 파일을 모두 올렸다
- [ ] 제출 확인 화면이나 확인 메일을 캡처해 팀 대화방에 올렸다
- [ ] 제출한 최종 파일을 팀 공유 폴더에 보관했다

## 제출한 뒤

- [ ] 12월 3일(목) 예선 결과를 확인한다
- [ ] 본선에 가면 12월 16일(수)까지 10분 발표 자료를 이메일로 낸다
- [ ] 12월 18일(금) 본선에 세 명 모두 참석한다
