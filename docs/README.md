## 문서 사이의 약속

- **수치의 정본은 사실 카드다.** 쪽 파일과 발표 글은 사실 카드의 번호(`F-01`, `S-01`)를 근거로 단다.
- **구조의 정본은 design 폴더다.** 쪽 파일은 그 내용을 쉬운 말로 옮긴 것이다. 둘이 다르면 design을 먼저 고치고 쪽 파일을 맞춘다.
- **결정은 decisions 폴더에 남긴다.** 방향을 바꾸면 기존 기록을 지우지 않고 새 기록을 추가한다.
