# 용어집

제안서와 발표에서는 "쉬운 말"을 먼저 쓰고, 전문 용어는 괄호로 한 번만 덧붙인다. 전문 용어를 꼭 써야 하는 쪽(6쪽, 7쪽)에서도 처음 나올 때는 쉬운 말로 푼다.

## 서비스

| 용어 | 쉬운 말 | 정확한 뜻 |
|---|---|---|
| 무인 자율주행차, 레벨4 | 운전자가 타지 않는 자율주행차 | 정해진 구역에서 사람의 개입 없이 주행하는 단계 |
| 원격관제, 원격지원 | 상황실에서 사람이 화면을 보고 차를 돕는 일 | 관제센터의 요원이 차량의 요청에 조언을 주는 운영 기능. 직접 조종하는 원격 운전과 다르다 |
| 관제사 | 상황실 직원 | 원격지원을 맡는 사람 |
| 확인형 질문 | "지금 지나가도 되나요?" 같은 질문 | 예, 아니오나 상태값으로 답할 수 있어 기계가 답하기 쉬운 요청 |
| 차로 점유 | 차가 도로를 막고 서 있는 것 | 답을 기다리는 차량이 주행 차로에 멈춰 있는 상태 |
| 갓길 대피 | 길을 비켜 서는 것 | 기한 안에 도움을 못 받으면 차로 밖으로 이동해 정차하는 동작 |
| 응답 마감시각 | 이 시간 안에 답이 와야 부드럽게 설 수 있는 한계 | 완만한 감속으로 정지선 앞에 설 수 있는 마지막 지점에 닿기 전까지의 시간 |
| 정보 신선도 | 정보가 찍힌 지 얼마나 됐는가 | 지금 시각에서 관측 시각을 뺀 값. 영어로 Age of Information |
| 유효기간 | 이 시각이 지나면 쓰지 않는 정보의 기한 | 응답에 붙는 만료 시각 |

## 교차로

| 용어 | 쉬운 말 | 정확한 뜻 |
|---|---|---|
| 신호제어기 | 신호등을 움직이는 장치 | 교차로의 신호 상태를 정하고 내보내는 장비 |
| 도로변 센서 | 길가에 단 감지 장치 | 교차로에 설치한 레이다와 라이다 |
| 4D 레이다 | 전파로 움직임을 재는 장치 | 거리, 방향, 높이, 속도를 함께 재는 레이다 |
| 라이다 | 빛으로 모양을 재는 장치 | 레이저로 주변을 3D 점으로 측정하는 센서 |
| RSU | 길가의 통신 장치 | 차량과 직접 통신하는 도로변 장치 (Roadside Unit) |
| 구역 상태 | 그 자리에 무엇이 있는지 | 점유, 관측상 비어 있음, 확인 불가의 세 가지 |
| C-ITS | 도로가 차에 정보를 방송해 주는 체계 | 차세대 지능형 교통 체계. 국내는 LTE-V2X 방식으로 정해졌다 |

## 통신

| 용어 | 쉬운 말 | 정확한 뜻 |
|---|---|---|
| 기지국 | 휴대전화가 연결되는 동네 안테나 | 이동통신 단말과 무선으로 연결되는 망의 접속 지점 |
| 엣지 서버 | 교차로나 기지국 바로 옆에 둔 컴퓨터 | 데이터가 생기는 곳 가까이에서 계산하는 서버 |
| 상향, 하향 | 차에서 기지국으로 올라가는 방향, 그 반대 | 단말에서 망으로 보내는 방향이 상향이다. 영상을 올려 보낼 때 상향 용량이 문제가 된다 |
| 지연 | 보낸 뒤 도착할 때까지 걸리는 시간 | 메시지의 종단 간 전달 시간 |
| AI-RAN | 기지국 장비에서 AI도 함께 돌리는 방식 | 무선 접속망의 연산 자원에서 통신 기능과 AI를 함께 운영하는 구조 |
| 기지국 AI | 기지국 옆에서 도는 AI | AI-RAN 장비에서 차량이 보낸 사진을 보고 조언하는 모델 |
| 네트워크 슬라이싱 | 버스전용차로 같은 통신 전용 차선 | 한 망을 논리적으로 나눠 특정 서비스에 자원을 따로 주는 기술 |
| 품질 보장 API | 필요한 순간에 통신 품질을 요청하는 창구 | 통신사가 외부 서비스에 여는 품질 요청 인터페이스 |
| 5G 직접통신, NR 사이드링크 | 기지국을 거치지 않고 차와 도로 장치가 직접 주고받는 통신 | 단말 사이의 직접 무선 통신. 3GPP Rel-16부터 1:1 통신과 수신 확인을 지원한다 |
| LTE-V2X | 지금 국내 표준인 차량 통신 방식 | LTE 기반 차량 통신. 직접통신은 방송만 지원한다 |
| 기지국 전환 | 달리는 차가 다음 기지국으로 넘어가는 순간 | 핸드오버. 이때 지연이 잠깐 커질 수 있다 |
| 품질 예측 통지 | 통신이 나빠질 것을 미리 알려 주는 기능 | 망이 통신 품질 변화 예측을 서비스 서버에 알리는 절차 |
| 통신·센싱 융합 | 기지국 전파로 물체를 감지하는 기술 | 통신 신호의 반사를 분석해 거리와 속도를 재는 6G 기술. 연구 단계다 |

## 통신 모듈

| 용어 | 쉬운 말 | 정확한 뜻 |
|---|---|---|
| SafeLink | 긴급한 정보가 제때 도착하게 하는 통신 부분 | 메시지 등급, 기한, 경로를 정하는 ASK의 통신 모듈 |
| 긴급, 중요, 일반 | 얼마나 급한 정보인가 | 메시지 등급. 보고서의 P1, P2, P3이고 코드의 tier 1, 2, 3이다 |
| 급한 순서대로 보내기 | 마감이 가까운 것부터 보내기 | 등급과 마감시각을 기준으로 한 우선순위 전송 |
| 기지국을 거치는 경로 | 휴대전화처럼 기지국을 지나는 길 | 5G 무선 접속 경로. 보고서의 L1, 코드의 A |
| 보조 경로 | 또 하나의 길 | 직접통신 같은 두 번째 경로. 보고서의 L2, 코드의 B |
| 두 경로로 함께 보내기 | 같은 내용을 두 길로 동시에 보내기 | 패킷 중복 전송 |
| 필요할 때만 두 경로 | 통신이 나쁘거나 급할 때만 두 길을 쓰기 | 선택적 패킷 중복 |

## 모의실험

| 용어 | 쉬운 말 | 정확한 뜻 |
|---|---|---|
| 모의실험 | 컴퓨터로 해 본 가상 실험 | 가정값으로 돌린 소프트웨어 시뮬레이션 |
| 가정값 | 실제로 재지 않고 정해 넣은 숫자 | 모의실험의 입력값. 근거가 생기면 바꾼다 |
| 시드 | 같은 실험을 다시 할 때 쓰는 번호 | 난수 생성의 초깃값. 시드가 같으면 결과가 같다 |
| 차로 점유 차량·분 | 도로를 막은 차량 수를 시간으로 더한 값 | 10대가 3분 막으면 30이다 |
| 제때 유효하게 도착한 비율 | 기한 안에, 오래되지 않은 상태로 도착한 비율 | 응답 기한과 허용 나이를 모두 만족한 긴급 메시지의 비율 |
