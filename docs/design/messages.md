# 메시지와 응답 기한

차량과 교차로가 주고받는 메시지의 항목, 응답 기한의 계산, 도착한 정보를 쓰기 전의 검사를 정리했다. 요청과 응답 항목은 연구실 브리핑 05장, 기한의 여유 항과 신선도 검사는 SafeLink 보고서 4장을 바탕으로 했다.

## 요청 메시지

차량이 보낸다. 작아야 한다. 영상은 담지 않는다.

| 항목 | 뜻 | 예 |
|---|---|---|
| 요청 ID | 응답과 짝을 맞추는 번호 | `req-000123` |
| 차량 ID | 요청한 차량 | `veh-17` |
| 질문 종류 | 신호 상태, 구역 상태, 진행 확인, 경로 조언 | `구역 상태` |
| 예정 진행 방향 | 직진, 좌회전, 우회전 | `우회전` |
| 요청 구역 | 답이 필요한 구역 | `교차로 12, 구역 B` |
| 응답 마감시각 | 이 시각까지 답이 와야 한다 | 보낸 시각 + 0.71초 |
| 차로 점유 여부 | 지금 도로를 막고 서 있는가 | `아니오` |

차로 점유 여부는 3단계에서 관제사와 영상 자원을 배정하는 순서에 쓴다.

## 응답 메시지

엣지 서버가 보낸다.

| 항목 | 뜻 | 예 |
|---|---|---|
| 요청 ID | 어느 요청에 대한 답인가 | `req-000123` |
| 답 | 신호 상태, 구역 상태, 또는 조언 | `관측상 비어 있음` |
| 답의 출처 | 신호제어기, 도로변 센서, 기지국 AI, 관제사 | `도로변 센서` |
| 관측 시각 | 센서가 실제로 본 시각 | 12:00:00.120 |
| 생성 시각 | 응답을 만든 시각 | 12:00:00.150 |
| 유효기간 | 이 시각이 지나면 쓰지 않는다 | 12:00:00.350 |
| 필요 시 위험 객체 | 위치와 속도 | 보행자, 구역 B 진입 중 |

관측 시각과 생성 시각은 다를 수 있다. 센서가 본 뒤 엣지가 응답을 만드는 데 시간이 걸리기 때문이다. 신선도는 관측 시각으로 잰다.

## 응답 기한

차량이 완만하게 감속해도 정지선 앞에 설 수 있는 마지막 지점에 닿기 전까지가 기한이다. 요청마다 다르고, 정지선에 가까울수록 짧다.

```
정지에 필요한 거리   d_stop   = v² / (2a)
남은 시간           T_margin = max(0, (d − d_stop) / v)
응답 기한           D        = max(0, T_margin − T_판단 − T_제동 − T_안전여유)
```

`v`는 속도, `a`는 계획 감속도, `d`는 정지선까지의 거리다.

| 요청 지점 | 여유 거리 | 남은 시간 | 여유 0.14초를 뺀 기한 |
|---|---|---|---|
| 정지선 100m 전 | 약 52m | 약 3.7초 | 약 3.6초 |
| 정지선 60m 전 | 약 12m | 약 0.85초 | 약 0.71초 |

계산 예시다(C-01). 시속 50km(13.9m/s), 감속도 2m/s²를 가정하면 정지에 약 48.2m가 필요하다. 여유 0.14초는 모의실험 코드에서 쓴 가정값이며, 실제 값은 차량의 판단 시간과 제동 실행 시간을 측정해 정한다.

**주의.** "남은 시간" 전부를 통신에 쓸 수 있는 것이 아니다. 고정된 100ms 같은 값을 규격 요구인 것처럼 쓰지 않고, 요청마다 기한을 계산한다.

## 신선도 검사

메시지가 도착했다는 것과 그 정보를 써도 된다는 것은 다르다. 차량은 답을 쓰기 전에 다음을 확인한다.

1. 요청 ID가 자기가 보낸 요청과 맞는가.
2. 답의 출처가 믿을 수 있는 곳인가.
3. 지금 시각에서 관측 시각을 뺀 값(정보의 나이)이 허용 범위 안인가.
4. 유효기간이 지나지 않았는가.
5. 같은 답이 두 경로로 왔다면 하나만 쓴다.

하나라도 통과하지 못하면 그 답은 "확인 불가"로 처리하고, 다음 단계로 넘어간다.

| 등급 | 예 | 허용하는 정보의 나이 (모의실험 가정) |
|---|---|---|
| 긴급 | 정지선이 가까운 차량의 구역 상태 | 0.23초 |
| 중요 | 신호 변경, 접근 중인 보행자 | 0.65초 |
| 일반 | 멀리 있는 차량의 사전 정보 | 2초 |

허용 나이는 모의실험에서 쓴 가정값이다. 사실 카드의 S-02를 인용할 때 이 가정을 함께 밝힌다.
