# 쉬운 말 쓰기 규칙

제안서와 발표는 통신을 배우지 않은 대학생이 읽고 바로 이해할 수 있어야 한다. 심사위원이 교수여도 마찬가지다. 쉬운 글은 전문가에게도 빨리 읽히고, 대회 안내문도 기술 소개보다 "어떤 문제를 풀고 무엇이 달라지는지"를 쓰라고 한다.

## 누구에게 쓰는가

전공이 다른 1학년 친구를 떠올린다. 이 친구는 5G가 "빠른 통신"이라는 것만 안다. 자율주행차는 뉴스에서 봤고, 기지국이 무엇인지는 잘 모른다. 똑똑하지만 우리 분야의 말을 모르는 사람이다.

## 여덟 가지 규칙

| | 규칙 | 예 |
|:-:|---|---|
| 1 | **장면부터 쓴다.** 개념보다 일어난 일을 먼저 말한다 | "2023년 8월 금요일 밤, 무인택시 열 대가 도로 한가운데 멈춰 섰습니다." |
| 2 | **한 문장에 한 가지만 담는다.** 쉼표로 세 가지를 잇지 않는다 | "차가 묻습니다. 교차로가 답합니다." |
| 3 | **쉬운 말을 먼저 쓴다.** 전문 용어는 괄호로 한 번만 덧붙인다 | "기지국 옆에서 AI를 돌리는 방식(AI-RAN)" |
| 4 | **비유는 하나만 쓴다.** 끝까지 같은 비유로 간다 | 상황실에 전화를 거는 차, 통화 중인 상황실 |
| 5 | **숫자는 한 쪽에 두세 개만 쓴다.** 단위와 출처를 함께 적는다 | "54%에서 92%로 (가상 실험, 가정값 기준)" |
| 6 | **문장을 끝까지 쓴다.** "~함", "~임"으로 끊지 않고 "~합니다"로 맺는다 | "급한 요청이 먼저 갑니다." |
| 7 | **영어 약어를 줄인다.** 꼭 써야 하는 것만 남긴다 | AI-RAN, 5G는 남기고 QoS, AoI, EDF는 풀어 쓴다 |
| 8 | **약속하지 않는다.** 할 수 있는 만큼만 말한다 | "보장합니다" 대신 "줄입니다" |

## 기계가 쓴 것처럼 보이는 표현

아래 표현이 보이면 글이 뻔해 보이고 믿음이 떨어진다. 고쳐 쓴다.

| 이렇게 쓰지 않는다 | 왜 | 이렇게 쓴다 |
|---|---|---|
| 혁신적인 솔루션을 제공합니다 | 무엇을 하는지 알 수 없다 | 교차로가 먼저 답합니다 |
| ~을 통해 ~을 극대화합니다 | 번역한 말투다 | ~해서 ~이 줄어듭니다 |
| 패러다임, 시너지, 생태계 | 뜻이 비어 있다 | 쓰지 않는다 |
| 안전하고, 효율적이며, 확장 가능한 | 세 개를 맞춰 늘어놓은 꾸밈말이다 | 근거가 있는 것 하나만 쓴다 |
| 첫째, 둘째, 셋째가 쪽마다 나온다 | 틀에 맞춘 티가 난다 | 순서가 중요할 때만 번호를 단다 |
| ~라고 할 수 있습니다, ~것으로 보입니다 | 자신 없는 말투다 | 아는 것은 단정하고, 모르는 것은 모른다고 쓴다 |
| 본 제안은, 본 서비스는 | 공문서 말투다 | 저희는, ASK는 |
| 핵심은 ~입니다 (여러 번) | 무엇이 핵심인지 흐려진다 | 한 번만 쓴다 |
| ~에 있어서, ~을 가능하게 합니다 | 영어를 옮긴 말투다 | 우리말 동사로 바꾼다 |
| 굵은 글씨와 쌍점이 문단마다 나온다 | 눈이 갈 곳을 잃는다 | 쪽마다 한두 곳만 강조한다 |
| 문장 길이와 끝맺음이 모두 같다 | 기계가 찍어 낸 느낌이 난다 | 짧은 문장과 긴 문장을 섞는다 |
| 다양한, 효과적으로, 최적의 | 꾸밈말이 정보를 가린다 | 빼거나 숫자로 바꾼다 |

## 고쳐 쓰기 예

**예 1**

> 고치기 전: 본 서비스는 Deadline-Aware Scheduling을 기반으로 P1 메시지의 적시 전달률을 향상시킴.
>
> 고친 뒤: 마감이 가까운 요청부터 보냅니다. 가상 실험에서 긴급한 정보가 제때 도착한 비율이 54%에서 92%로 올랐습니다.

**예 2**

> 고치기 전: 엣지 서버가 SPaT 및 구역 점유 상태를 융합하여 V2I 응답을 구성함.
>
> 고친 뒤: 교차로 옆 컴퓨터가 신호 색과 횡단보도 상황을 모아 차에 답합니다.

**예 3**

> 고치기 전: AI-RAN 기반의 혁신적 원격지원 패러다임을 통해 운영 효율을 극대화합니다.
>
> 고친 뒤: 기지국 옆에 AI를 두면 사진을 멀리 보내지 않아도 됩니다. 그만큼 답이 빨리 옵니다.

## 자주 쓰는 말 바꾸기

전체 목록은 [용어집](../design/glossary.md)에 있다.

| 전문 용어 | 쉬운 말 |
|---|---|
| 무인 자율주행차, 레벨4 | 운전자가 타지 않는 자율주행차 |
| 원격관제 | 상황실에서 사람이 화면을 보고 차를 돕는 일 |
| 엣지 서버 | 교차로나 기지국 바로 옆에 둔 컴퓨터 |
| 신호제어기 | 신호등을 움직이는 장치 |
| 도로변 센서 | 길가에 단 센서 |
| 응답 마감시각 | 답을 기다릴 수 있는 시간 |
| 정보 신선도 | 정보가 얼마나 오래됐는가 |
| 패킷 중복 전송 | 두 길로 함께 보내기 |
| 네트워크 슬라이싱 | 버스전용차로 같은 통신 전용 차선 |
| 시뮬레이션 | 가상 실험, 모의실험 |

## 비유는 이것 하나로

> 무인차가 길에서 곤란해지면 회사 상황실에 전화를 겁니다. 평소에는 금방 받습니다. 그런데 정전 같은 일이 터지면 수십 대가 한꺼번에 전화를 걸어 통화 중이 됩니다. ASK는 상황실에 전화하기 전에 바로 옆 교차로가 먼저 대답해 주는 서비스입니다.

다른 비유(119, 콜센터, 택배)를 섞지 않는다. 6쪽의 "두 길로 함께 보내기"를 설명할 때만 택배 비유를 한 번 쓴다.

## 다 쓴 뒤 검사

- [ ] **소리 내어 읽었다.** 숨이 차는 문장은 둘로 잘랐다
- [ ] **친구에게 물어봤다.** 전공이 다른 친구에게 1분 동안 설명하고 "그래서 뭘 하는 거야?"라고 되물었을 때 한 문장으로 답이 나왔다
- [ ] **제목만 읽어 봤다.** 쪽 제목 열 개만 이어 읽어도 이야기가 된다
- [ ] **숫자를 확인했다.** 모든 숫자에 [사실 카드](../evidence/facts.md) 번호가 있다
- [ ] **위 표의 표현이 남아 있지 않다**

## AI 도우미에게

글을 쓰거나 다듬을 때 이 문서의 규칙을 따른다. 다 쓴 뒤 "기계가 쓴 것처럼 보이는 표현" 표를 다시 보고 남은 것을 고친다. 사용자가 쓴 문장의 말투는 되도록 살리고, 뜻이 바뀌지 않는 선에서만 고친다.
